The Build.

One analog input controls four independent sound behaviors.

A photoresistor connected to analog pin A0 continuously measures environmental light. The Arduino converts that reading into values that can control sound in real time.

Four slide switches independently enable the instrument's four buzzer modes, allowing multiple behaviors to operate together instead of limiting the system to one fixed output.

How It Works.

Each switch activates a different relationship between the sensor reading and sound output.

01 CONTINUOUS

Light → Pitch

Light intensity is mapped to a changing buzzer frequency.

300–2000 Hz
02 RHYTHM

Light → Beat

The sensor reading changes the timing between repeating buzzer pulses.

200–600 ms
03 THRESHOLD

Low-Light Trigger

A dedicated buzzer activates when the light reading drops below the threshold.

sensor < 500
04 THRESHOLD

High-Light Trigger

A separate buzzer activates when the light reading rises above the threshold.

sensor > 500

Engineering Highlights.

01

Analog Sensing

The photoresistor is sampled through A0 using the Arduino's 0–1023 analog input range.

02

Real-Time Mapping

Sensor values are converted into usable frequency and timing ranges for sound output.

03

Independent Controls

Four INPUT_PULLUP switches independently enable each sound behavior.

04

Non-Blocking Timing

The beat uses millis() timing so the system can continue reading the sensor and switches while rhythm generation is active.

PROJECT TAKEAWAYS

Turning sensor data into real-time behavior.

This project gave me hands-on experience connecting analog sensing, digital controls, and sound output in one embedded system. The most important part was designing the program so changing sensor data and multiple switch inputs could be processed continuously without interrupting one another.
