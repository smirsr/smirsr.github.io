Light-Controlled Instrument

An Arduino-based interactive instrument that transforms real-time light sensor readings into sound using analog input processing, threshold logic, switch control, variable pitch, and variable beat timing.

Arduino Uno C/C++ Analog Sensors Embedded Systems

01.

Project Overview .

The Light-Controlled Instrument is an embedded system built around an Arduino Uno that uses environmental light as an interactive input for generating sound.

A photoresistor continuously measures light intensity through analog pin A0. The Arduino processes that reading while also monitoring four slide switches that independently control four buzzer functions.

Light can control pitch, control beat speed, or trigger dedicated low-light and high-light sounds. Because each function has its own switch, several sound behaviors can operate together.

Circuit Design .

The circuit combines an Arduino Uno, a photoresistor, four slide switches, and four buzzers. The photoresistor provides the changing analog input while each switch independently enables one audio behavior.

05.

Control Logic .

Each pass through the main loop reads the photoresistor and the four switches. The switches use INPUT_PULLUP, meaning a LOW digital reading represents an enabled sound function.

01 Read the photoresistor using analogRead(A0)
02 Read all four INPUT_PULLUP switch states
03 Map light input into a 300–2000 Hz pitch range
04 Map light input into a 200–600 ms beat interval
05 Compare the sensor value against the threshold of 500
06 Update each enabled buzzer

✦ NON-BLOCKING TIMING

Beat Timing with millis()

The beat output uses millis() and stores the time of the previous state change. Once the required interval has passed, the beat state toggles between ON and OFF.

This avoids using a long blocking delay for the rhythm, allowing the program to continue reading the light sensor and switches while the beat runs.

06.

Sound Controls .

The four sound functions are independently enabled, meaning the user can combine multiple sound behaviors rather than selecting only one mode at a time.

SOUND 01

Light-Controlled Pitch

The main buzzer continuously changes frequency according to the photoresistor reading.

Dark → Higher Pitch
Bright → Lower Pitch
Range: 300–2000 Hz
SOUND 02

Light-Controlled Beat

The beat buzzer repeatedly switches between ON and OFF. Light determines how quickly the state changes.

Dark → Slower Beat
Bright → Faster Beat
Interval: 200–600 ms
SOUND 03

Low-Light Trigger

When enabled, the dedicated low-light buzzer activates whenever the sensor value falls below 500.

Sensor < 500 → ON
Sensor ≥ 500 → OFF
SOUND 04

High-Light Trigger

When enabled, the dedicated high-light buzzer activates whenever the sensor value rises above 500.

Sensor > 500 → ON
Sensor ≤ 500 → OFF

07.

Technical Details .

Analog Input

Photoresistor values are read across the Arduino's 0–1023 analog range.

Pitch Mapping

Sensor values are mapped inversely from 2000 Hz to 300 Hz.

Beat Mapping

Sensor values are mapped from a 600 ms interval to a 200 ms interval.

Threshold

500 separates the low-light and high-light trigger regions.

Switch Inputs

Four INPUT_PULLUP digital inputs allow each sound behavior to be enabled independently.

Loop Update

A short 10 ms loop delay is used while the beat timing itself is controlled with millis().
